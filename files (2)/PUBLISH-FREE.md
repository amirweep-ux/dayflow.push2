# منتشر کردن Day Flow به‌صورت رایگان (بدون خرید سرور و دامنه)

این نسخه **بدون سرور** کار می‌کنه: همه‌ی داده‌ها روی گوشی هر کاربر می‌مونه. فقط فایل‌های ثابت لازمه و میزبانی رایگان براش کافیه. آدرس اپ یه زیردامنه‌ی رایگان می‌شه (مثل `اسمت.github.io/dayflow`) و HTTPS هم خودکار داره.

## چی کار می‌کنه و چی نه
- ✅ نصب روی صفحه‌ی اصلی گوشی، کار کردن بدون اینترنت، همه‌ی بخش‌های اپ (تسک، عادت، تایمر، آمار، رنک، کوچ قاعده‌محور، پشتیبان)
- ❌ حساب کاربری، همگام‌سازی بین دستگاه‌ها، پشتیبان ابری، چت‌بات هوشمند، اعلان یادآوری. اینا به سرور نیاز دارن و توی این نسخه خاموشن (بخش «حساب کاربری» توی تنظیمات پنهانه).
- جابه‌جا کردن داده بین دو دستگاه: «بیشتر ← پشتیبان» فایل می‌سازه و روی دستگاه دوم بازیابی می‌شه.

## روش ۱: GitHub Pages (پیشنهادی)
1. توی github.com یه حساب رایگان بساز (فقط ایمیل لازمه).
2. **New repository** بزن. اسم: `dayflow` — نوع: **Public** — Create.
3. توی صفحه‌ی مخزن، روی **uploading an existing file** بزن و **همه‌ی فایل‌های همین پوشه** (`index.html`، `sw.js`، `manifest.webmanifest` و چهار تا `icon-…png`) رو بکش داخلش. بعد **Commit changes**.
4. **Settings ← Pages**: بخش Source رو **Deploy from a branch** بذار، Branch رو `main` و پوشه رو `/ (root)`، و Save.
5. بعد از ۱ تا ۲ دقیقه آدرس اپ می‌آد: `https://اسم-کاربری-تو.github.io/dayflow/`

## روش‌های دیگه (همه رایگان و بدون کارت بانکی، ولی صفحه‌ی ثبت‌نامشون ممکنه عوض شده باشه)
- **Cloudflare Pages:** حساب رایگان ← Workers & Pages ← Create ← Pages ← Upload assets ← پوشه رو آپلود کن. آدرس: `اسم.pages.dev`
- **Netlify:** حساب رایگان ← Sites ← Add new site ← Deploy manually ← پوشه رو بکش داخلش. آدرس: `اسم.netlify.app`

اگه یکی از اینا از جایی که هستی بسته یا کنده، یکی دیگه رو امتحان کن. من نمی‌تونم از اینجا ببینم کدوم برای تو در دسترسه.

## تست روی گوشی
1. آدرس رو توی مرورگر گوشی باز کن.
2. **اندروید (Chrome):** منو ← Install app یا Add to Home screen.
   **آیفون (Safari):** دکمه‌ی Share ← Add to Home Screen. **حتماً نصب کن**، چون Safari داده‌ی سایت‌های نصب‌نشده رو بعد از مدتی بی‌استفاده پاک می‌کنه، و داده‌ی اپ نصب‌شده با داده‌ی تب Safari جداست؛ پس بعد از نصب، دوباره شروع کن.
3. حالت هواپیما رو روشن کن و اپ رو باز کن؛ باید بالا بیاد.

## به‌روزرسانی
فایل‌های جدید رو روی همون مخزن جایگزین کن. داخل `sw.js` شماره‌ی `dayflow-1.0.0` رو بالا ببر (مثلاً `dayflow-1.0.1`) تا حافظه‌ی قدیمی گوشی‌ها پاک بشه. کاربرها با بار بعدی باز کردن اپ نسخه‌ی جدید رو می‌گیرن.

## قبل از اینکه لینک رو به بقیه بدی
- متن‌های «قوانین و حریم خصوصی» داخل اپ هنوز جای خالی `[نام ارائه‌دهنده]` و `[ایمیل پشتیبانی]` و `[قانون و مرجع]` دارن. بگو چی بنویسم تا جایگزین کنم و فایل جدید بدم. این‌ها پیش‌نویس‌ان و برای انتشار گسترده بهتره یه آدم آگاه بخونتشون.
- به کاربرها بگو **مرتب از «بیشتر ← پشتیبان» فایل بگیرن**، چون بدون سرور، پاک شدن اطلاعات مرورگر یعنی از بین رفتن داده‌ها.

## بعداً، وقتی امکانش بود
اگه یه روز خواستی حساب و همگام‌سازی داشته باشی، پوشه‌ی `dayflow-release` (سرور و راهنمای `DEPLOY.md`) آماده‌ست. اون نسخه به یه سرور (هر چند کوچیک) و ترجیحاً یه دامنه نیاز داره.
